
# 📸 Image Gallery

A modern, responsive image gallery built using **HTML, CSS, and JavaScript** as part of the CodeAlpha Tasks.

The project provides an interactive way to explore images through a clean grid layout, smooth hover effects, category filters, and an image lightbox with navigation controls.

## 🎯 About the Project

The Image Gallery is a frontend web development project designed to display images in an attractive and user-friendly layout.

It demonstrates the practical use of HTML for page structure, CSS for styling and responsive layouts, and JavaScript for interactive functionality.

The project is designed to work across mobile phones, tablets, laptops, and desktop screens.

## 🖱️ How to Use

1. Open the Image Gallery in your browser.
2. Browse the images displayed in the gallery grid.
3. Select a category to filter images by type.
4. Click an image to open it in the lightbox.
5. Use the Next and Previous buttons to navigate between images.
6. Close the lightbox to return to the main gallery.
7. Resize the browser window to see the responsive layout in action.

## 📱 Responsive Design

The gallery uses responsive CSS techniques to provide a consistent browsing experience on:

- Mobile phones
- Tablets
- Laptops
- Desktop computers

The layout adapts to available screen space to keep images accessible and visually organized.
